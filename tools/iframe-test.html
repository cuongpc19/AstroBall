AstroBall at every iframe size the host uses

Serve the build first — npx vite preview — then open this file. The host runs the game between 800×450 and 1920×1080. Both are 16:9, so Scale.FIT covers the whole range and this page is a verification, not a rewrite. The phone size is the one that is a different ratio, and the one to look at hardest.

Look for: the board fully inside the frame at every size, letterbox bars painted the game's own colour rather than white or black, and no scrollbar inside any frame.
